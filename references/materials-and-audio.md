# 素材与音频

## 材料含义

| 文件 | 用途 | 是否必须由用户预先提供 |
|---|---|---|
| MXL / MusicXML / XML | 结构化曲谱：音高、节拍、声部、延音等；MXL是压缩MusicXML | 不要求用户提供；先检查本地，缺失时查找下载，也可从MuseScore源谱导出 |
| MSCZ / MSCX | MuseScore原生曲谱 | 可作为唯一初始材料，后续导出其他格式 |
| MID / MIDI | 演奏事件与速度，用作动画时间源；本身不是录音 | 制作时需要，可从确认过的曲谱导出 |
| WAV / OGG / MP3 / FLAC | 可播放的声音 | 不必预先提供，可合成 |
| PDF / 图片 | 检查谱面与排版的参考 | 有结构化曲谱时可选，不能替代可解析音符 |

OGG是容器，常见为Vorbis压缩音频；不要仅凭扩展名判断内部编码。用FFprobe查看。转成WAV便于处理，但不能恢复压缩丢失的信息，也不会自动修复起点或速度不一致。

## 补齐资料的决策顺序

先按 [查找、下载与匹配](acquisition.md) 确立一份源谱。无需为了凑齐材料单独下载PDF；可视SVG由Verovio生成。

1. 本地已有匹配的MIDI和音频：验证通过就复用，不装MuseScore。
2. 缺MIDI或音频，但已有MuseScore Studio 4或已验证可用的转换/合成工具与音源：从同一源谱生成缺项，无需为避免安装而四处寻找其他演奏版本。优先复用已有工具，不强行升级。
3. 本地没有所需生成工具：先在源谱的同一页面、仓库或发布版本找配套MIDI/音频，核查是否确实对应。必要时扩展搜索，但不同来源文件必须完成匹配检查；无需安装即可得到可靠配套时直接使用。
4. 没有可靠配套，或适配成本高于同源生成：告知缺失文件、已找到源谱、搜索结果及MuseScore可补齐的内容，确认是否允许下载安装MuseScore Studio 4。已明确授权无需重复确认。用户不愿安装时说明可用替代工具/配套来源或当前缺口，不宣称已满足制作条件。

应优先保证同版本匹配，其次减少新增安装，不能把“全部从网络下载”作为固定要求。推荐生成方式是从同一份确认过的MuseScore谱导出MXL、MIDI和WAV。可以先导入用户MXL再导出；只有MIDI时也可以导入，但需检查量化、拍号、voice、左右手和连音。MIDI转谱再导出可能改变表情时间，不可承诺保留原始真人演奏。

同源不代表天然同步：反复展开、装饰音、tempo、声音引擎延迟与尾音都需核查。先生成短段测试，比较首音、几个中间起音和末尾。优先使用能稳定导出的已有音源；不默认要求下载大型音源库。包内不提供钢琴音源。

已有音频且用户要求保留时，不悄悄换合成版本。若只差固定偏移可校正；若节奏漂移，需要时间对齐或用户同意替换。不得将原项目某个OGG的偏移量复用到新曲。

## MuseScore调用

检查本机现有MuseScore Studio及其实际可执行文件，不硬编码作者的安装路径。缺失且确实需要时，先说明具体缺失的MIDI/音频等材料可以从现有XML生成，取得安装同意后从官方渠道安装；需要管理员权限、交互安装或大音源下载时按环境权限处理。当前创建Skill的任务不需要安装MuseScore。

通过本机帮助/版本或界面核实可用功能。可执行文件名称因平台而异；官方CLI文档提示部分内容沿自MuseScore 3，以下为需本机确认的参数形状，`<MuseScore可执行文件>`是占位符：

```text
<MuseScore可执行文件> -o work/score.mxl source.mscz
<MuseScore可执行文件> -o work/performance.mid source.mscz
<MuseScore可执行文件> -o work/piano.wav source.mscz
```

先建立输出目录。以参数数组调用进程，路径有空格时不要拼接未转义shell字符串。不要用禁用合成器的参数导出声音。若版本/音源无法命令行导出，查看错误、使用官方支持的音源或GUI导出；不要无限重试或重置用户偏好。

FFprobe确认音频流、采样率与时长；检查非静音、起点、尾音与削波。听感判断需实际试听（若环境有听音工具则使用），不能把统计峰值当作试听。缺乏试听能力时明确说明。进入模板的音轨从音乐时间0开始，不预加5帧静音。
